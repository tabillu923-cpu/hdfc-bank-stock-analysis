
# HDFC Bank Stock Analysis Using Python

## Project Overview
This project analyses historical HDFC Bank stock data using Python
to understand annual returns, volatility, and long-term price growth.

## Objectives
- Clean and inspect historical stock data.
- Calculate daily stock returns.
- Calculate annual compounded returns.
- Measure daily and annualized volatility.
- Identify the best and worst performing years.
- Calculate Compound Annual Growth Rate (CAGR).
- Visualize annual returns and the risk-return relationship.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Findings
- Period analysed: approximately 27 years.
- Best year: 1999.
- Best annual return: 192.90%.
- Worst year: 2008.
- Worst annual return: -41.94%.
- Highest annualized volatility: 57.37% in 2008.
- Lowest annualized volatility: 13.40% in 2017.
- CAGR of adjusted closing price series: 27.64%.

## Methodology
Historical stock data was loaded into Pandas, checked for missing
values, and converted into a suitable format for analysis.
Daily returns were calculated from adjusted closing prices.
Annual returns were compounded from daily returns, and volatility
was annualized using approximately 252 trading days per year.

## Limitations
Historical performance does not guarantee future results.
The analysis does not include personal cash flows, taxes,
transaction costs, or a complete assessment of investment suitability.
